Void has NIRUPI installed as a separate session. ThinkPad had no active desktop
in the inspected process snapshot. No production session, PAM, package, browser
preference or NIRUPI file was changed by this checkpoint.

## Remaining high-value findings

- Config migration is still a deliberately small line-oriented helper, not a full
  TOML parser. Quoted keys/multiline values, symlink semantics and atomic validated
  activation need I06 before calling arbitrary user-config migration safe.
- Old installer performs component staging itself. Existing historical evidence
  shows new components requiring a second update. I07 must replace this with a
  target-installer handoff and move dependency provisioning before execution of
  newly staged shared-library-dependent binaries.
- Purge omits newer component directories. Ownership and documented scope need I08.
- Doctor prints missing configured commands without failing that diagnostic.
  Default browser is Brave but no browser is provisioned. Resolve provider policy
  explicitly rather than silently installing a large browser on every machine.
- Standalone WM version selection reads checkout bar metadata for other release
  versions. Reproduce against a real older tag before changing I09.
- Saver resize/input grabs, bounded/coalesced WM helpers, WM/bar validation parity,
  physical sleep/hotplug, text input and optional-app portability remain in queue.

No full clean-OS installation, deployment of 0.10.13, physical unlocking,
lid/suspend/resume, docking or exhaustive optional-app code audit was performed in
this checkpoint. Historical claims in the archived roadmap are not new evidence.
